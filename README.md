# Shell & Linux Fundamentals

**Holberton School · Software Engineering Coursework**

Command-line exercises covering navigation, file operations, shell expansions, pipelines, text filters and file permissions.

## Technology and concepts

Bash, Linux shell, file permissions, environment variables and text processing.

## Modules

| Directory | Focus |
| --- | --- |
| [`basics/`](./basics/) | Foundational commands and concepts covered in this module. |
| [`init_files_variables_and_expansions/`](./init_files_variables_and_expansions/) | Shell aliases, environment variables, expansions and arithmetic. |
| [`io_redirections_and_filters/`](./io_redirections_and_filters/) | Standard streams, redirection, pipelines and text filters. |
| [`permissions/`](./permissions/) | Linux user/group ownership, file modes and permission changes. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
